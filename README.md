# Disser

Работа над диссертацией. Модель распределения гаусса по матрице.

## Генератор кадров для запуска из PyCharm

Код разложен на три понятные части, чтобы файлы можно было перенести в другой проект без Jupyter:

1. `run_gaussian_simulator.py` — файл запуска и основные константы модели.
2. `gaussian_simulator/gaussian_math.py` — математические функции: пиксельный интеграл гауссианы, генерация модели, нормализация, crop 3×3, подгонка sigma и пересчет LSB↔Вт.
3. `gaussian_simulator/gaussian_app.py` — логика симулятора и интерактивное окно на PyQt с встроенными графиками `matplotlib`.

Важно: при расчете sigma из синтетического кадра из crop 3×3 сначала вычитается заданный `BACKGROUND_LSB`, а затем сигнал нормируется только по сумме. Это нужно, чтобы незашумленная модель не искажалась вычитанием минимума: если временной и геометрический шумы равны нулю, расчетная sigma должна совпадать с заданной с точностью численной оптимизации и ограничений crop 3×3.

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск

```bash
python run_gaussian_simulator.py
```

В файле `run_gaussian_simulator.py` можно заранее задать ширину/высоту кадра, центр пятна, sigma в пикселях, амплитуду, фон, временной шум, геометрический шум, фиксацию геометрического шума, разрядность АЦП и коэффициент `LSB_PER_PICOWATT`. По умолчанию используется 16 бит, то есть 65536 уровней яркости, и пересчет 60 младших разрядов на 1 пикоВатт.

`AMPLITUDE_LSB` — это пиковая добавка гауссоиды над фоном в разрядах АЦП: если фон равен 1000 LSB, а амплитуда 30000 LSB, то центральный пиксель идеальной гауссоиды будет около 31000 LSB до добавления шумов. `BACKGROUND_LSB` — это постоянный базовый уровень каждого пикселя до добавления гауссоиды и шумов.

Все вводные параметры в окне задаются аккуратными числовыми полями PyQt над изображениями: число можно вписать с клавиатуры или менять стрелками spinbox. Поля, чекбокс и кнопки разложены сеткой, поэтому они не перекрывают графики.

Окно показывает три изображения:

1. полный смоделированный зашумленный кадр в разрядах АЦП;
2. обрезку 3×3 вокруг максимального пикселя;
3. модель 3×3 с рассчитанной по взвешенному методу sigma.

`GEOMETRIC_SEED` — это начальное число генератора случайных чисел для геометрического шума. При одном и том же seed фиксированный геометрический шум будет воспроизводиться одинаково после сброса; если изменить seed, получится другая карта дефектов/неоднородностей пикселей.

Кнопка **Новый кадр** генерирует новый временной шум. Если включена фиксация геометрического шума, геометрическая компонента остается неизменной между кадрами до нажатия **Сброс геом. шума**.
